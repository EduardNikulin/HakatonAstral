# Фронтенд: база без воды

## Два мира
- **Бэкенд** — программа на сервере (FastAPI, порт 8000): хранит данные, решает «можно/нельзя».
- **Фронтенд** — JS-код, который браузер скачал и выполняет у пользователя. Своей базы нет:
  только память открытой страницы и localStorage (переживает перезагрузку).
- Общение одностороннее: фронт шлёт запрос -> бэк отвечает. Бэк первым не стучится.

## Инструменты (и почему они)
| Что | Зачем | Аналоги |
|---|---|---|
| Node.js + npm | запускать JS вне браузера и ставить библиотеки | bun, pnpm |
| Vite | dev-сервер (правка файла = мгновенный reload) + сборка в статику | webpack, CRA (устарел) |
| React | интерфейс из кусков-компонентов; меняешь переменную state — картинка обновляется сама | Vue, Svelte, Angular |
| Axios | HTTP-запросы: базовый URL один раз, заголовки автоматически | fetch (встроен, но руками) |
| React Router DOM | «страницы» без перезагрузки: URL -> компонент | TanStack Router |
| Context API | общая коробка данных на всё дерево (у нас — кто вошёл) | Redux, Zustand |

## Карта папок frontend/src
```
main.jsx        точка входа: монтирует React в div#root, включает роутер и AuthProvider
App.jsx         маршруты: / , /login , /register ; пока идёт проверка сессии — заглушка
components/     переиспользуемые куски интерфейса (Header — правый верхний угол)
pages/          целые экраны (Login, Register, Home)
services/api.js ЕДИНСТВЕННОЕ место походов на бэк: axios + автоподстановка токена
context/        глобальное состояние (AuthContext: user, loginAction, logoutAction)
styles.css      общие стили
```
Правило как на бэке: компоненты думают про внешний вид; сеть — в services; правила показов — в context.

## Состояние вместо ручного обновления
`const [user, setUser] = useState(null)` — меняешь setUser -> React сам перерисует.
`useEffect(..., [])` — один раз при появлении экрана (у нас: восстановить сессию по токену).
Объект меняют копией: `setUser({...user, role})`, иначе React не заметит подмены.

## Путь токена
1. POST /auth/login (form-data!) -> `{access_token}` -> saveToken() в localStorage.
2. Интерцептор axios лепит `Authorization: Bearer <токен>` в КАЖДЫЙ запрос — вручную нигде не пишем.
3. Открыли страницу заново -> useEffect зовёт GET /auth/me -> 200: пользователь восстановлен; 401: чистим, гость.
4. Выход = удалить токен из localStorage + setUser(null). JWT с сервера не забирается, он сам протухает.

## CORS
Браузер запрещает странице с localhost:5173 ходить на localhost:8000, пока бэк не разрешит.
Разрешение лежит в backend/app/core/config.py (CORS_ORIGINS, уже содержит :5173).
«blocked by CORS policy» в консоли = порт фронта не в списке.

## Отладка
