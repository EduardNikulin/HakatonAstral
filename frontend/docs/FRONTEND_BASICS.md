# Фронтенд: теория без метафор

Выжимка базы. Полное обучение — в чате с ассистентом.

## 1. Чем фронт отличается от бэка

- Бэкенд — программа на сервере, живёт постоянно, хранит данные, решает «можно/нельзя».
- Фронтенд — код (JS), который браузер скачивает один раз и выполняет у
  пользователя. Своё «хранилище» — только память страницы + localStorage
  (маленькое хранилище в браузере, переживает перезагрузку).
- Общаются строго так: фронт сам шлёт HTTP-запрос на бэк (fetch/axios), бэк
  отвечает JSON. Бэк никогда не «стучится» к фронту первым.

## 2. Инструменты (по одному абзацу)

- **Node.js** — среда, чтобы запускать JS вне браузера. Нужна только для сборки
  и разработки; конечный пользователь её не устанавливает.
- **npm** — менеджер пакетов: ставит библиотеки из package.json
  (`npm install`), команды-алиасы (`npm run dev`).
- **React** — библиотека, собирающая интерфейс из кусков-компонентов.
  Компонент = функция, которая возвращает разметку JSX (HTML внутри JS).
- **Vite** — сборщик: запускает локальный сервер разработки со мгновенным
  обновлением в браузере и упаковывает проект в статику для выкладки.
- **JSX** — синтаксис: `<div className="x">{имя}</div>`. Класс пишется
  `className`, потому что `class` в JS зарезервирован.
- **Axios** — библиотека для HTTP-запросов (обёртка над fetch), умеет
  подставлять заголовки автоматически через interceptors.
- **React Router DOM** — переключает «страницы» без перезагрузки: URL меняется,
  React показывает другой компонент. Защищённые маршруты проверяют, есть ли
  токен, иначе кидают на /login.
- **Context API** — способ передать данные (например, текущего юзера и токен)
  всем компонентам сразу, не протаскивая их через аргументы по цепочке.

## 3. Как устроена страница

```
main.jsx        точка входа: подключает React к <div id="root">, включает роутер
App.jsx         список маршрутов: какой URL -> какой компонент
pages/*.jsx     целые экраны (Login, Users...)
components/*.jsx переиспользуемые куски (кнопка, поле, карточка)
services/api.js axios-клиент: базовый URL бэка + автоподстановка токена
context/*       глобальное состояние (AuthContext: вошёл/не вошёл, роль)
```

Правило переноса логики с бэка то же: компоненты — только про внешний вид,
поход за данными и правила «что показывать» — в services и context.

## 4. Главный механизм: состояние вместо ручного обновления

В императивном коде ты сам меняешь текст элемента. В React ты меняешь
**переменную состояния** (`useState`), а React сам перерисовывает разметку.
Данные пришли с бэка -> положил в state -> картинка обновилась сама.

```jsx
const [user, setUser] = useState(null);   // переменная + функция её смены
useEffect(() => { /* запрос к бэку после первого показа */ }, []);
return user ? <p>Привет, {user.login}</p> : <p>Загрузка...</p>;
```

- `useState` — значение, при изменении которого компонент перерисовывается.
- `useEffect` — «сделай дело после появления на экране» (загрузка данных,
  подписки). Пустой массив `[]` в конце = выполнить один раз.
- Изменение объекта создаёт новый объект (`setUser({...user, role})`) — иначе
  React не заметит подмены и не перерисует.

## 5. Что такое CORS и почему оно бесит

Браузер по умолчанию запрещает странице с одного адреса (localhost:5173)
лазить на другой (localhost:8000). Сервер может явно разрешить это списком —
на бэке уже настроено в `main.py` (middleware CORS, порты фронта в allow-list).
Ошибка «CORS policy» в консоли браузера = почти всегда забытый порт в этом списке.

## 6. Хранение токена на фронте (наш рабочий путь)

1. Форма логина шлёт `POST /api/v1/auth/login` (form-data username/password).
2. Получили `access_token` -> кладём в `localStorage` и в AuthContext.
3. Axios-interceptor читает localStorage и добавляет каждому запросу
   `Authorization: Bearer <токен>` — руками в каждом месте не пишем.
4. Проверка «жив ли ещё вход»: `GET /auth/me`. 401 -> чистим всё на global
   interceptor и редирект на /login.
5. Выход = просто удалить токен из localStorage (на бэке JWT не отзывается).

## 7. Отладка

- Консоль браузера (F12) -> вкладка Network: видно каждый запрос, статус, тело.
  Любой спор «фронт послал / бэк вернул» решается там.
- Красный экран с текстом ошибки = React сказал, что сломалось (чаще: обращение
  к `null` до загрузки данных или опечатка в имени поля ответа).
- Vite отдаёт фронт на http://localhost:5173, Swagger бэка — http://localhost:8000/docs.
